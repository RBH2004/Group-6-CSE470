# BrandTruth Python Price Intelligence & Scraper Service

This service provides:
1. **Machine Learning / Anomaly Detection Engine** for fake e-commerce discounts based on statistical Z-scores and price variance.
2. **E-commerce Scraper Adapter** for Bangladesh stores (Daraz, Star Tech, Chaldal, Pickaboo).

## Running the Service
```bash
python python-service/app.py
```
Default URL: `http://127.0.0.1:5001`
